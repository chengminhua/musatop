# musatop

An interactive terminal monitor for Moore Threads GPUs.

面向摩尔线程 GPU 的交互式终端监控工具。

## 项目状态

目前处于仓库初始化阶段，尚未实现 GPU 数据采集和终端监控功能。

计划参考并复用 [nputop](https://github.com/youyve/nputop) 的部分代码，
逐步适配摩尔线程 GPU。`nputop` 源自
[nvitop](https://github.com/XuehaiPan/nvitop)。当前仓库尚未导入这些项目的代码。
